# Caravel_Kria

Initialize repo using 
``` tcl
   vivado -source vivado/caravel_generate.tcl -tclargs nexys_a7   # -> vivado/project/caravel_nexys/
```
``` tcl
   vivado -source vivado/caravel_generate.tcl -tclargs kria_kr26   # -> vivado/project/caravel_kria/
```
(Nexys A7-100t board file must be installed before creating the project, it can be installed via the xilinx store)
